# recast.styles()

Create reusable style definitions that can be applied to any React component.

## Syntax

```tsx
recast.styles(styleConfig)
```

<ParamField path="styleConfig" type="RecastStyles" required>
  Configuration object defining the styles, variants, modifiers, and defaults
</ParamField>

**Returns:** `RecastStylesObject` - A style object that can be applied to components or used to extract class names

## Configuration Properties

<AccordionGroup>
<Accordion title="base" icon="foundation">
Foundation classes applied to all instances:

<CodeGroup>
```tsx String Base (Simple)
const styles = recast.styles({
  base: "px-4 py-2 rounded font-medium"
})
```

```tsx Object Base (Complex)
const styles = recast.styles({
  base: {
    root: "rounded-lg border bg-white",
    header: "px-6 py-4 border-b",
    content: "px-6 py-4"
  }
})
```
</CodeGroup>
</Accordion>

<Accordion title="variants" icon="layer-group">
Mutually exclusive styling options (radio button behavior):

```tsx
variants: {
  variant: {
    primary: "bg-blue-500 text-white",
    secondary: "bg-gray-200 text-gray-900"
  },
  size: {
    sm: "px-3 py-1 text-sm",
    md: "px-4 py-2",
    lg: "px-6 py-3 text-lg"
  }
}
```
</Accordion>

<Accordion title="modifiers" icon="toggle-on">
Boolean flags that can be combined (checkbox behavior):

```tsx
modifiers: {
  disabled: "opacity-50 cursor-not-allowed",
  loading: "cursor-wait",
  fullWidth: "w-full"
}
```
</Accordion>

<Accordion title="defaults" icon="settings">
Default values to reduce prop repetition:

```tsx
defaults: {
  variants: { variant: "primary", size: "md" }
}
```
</Accordion>

<Accordion title="conditionals" icon="code-branch">
Apply styles only when specific conditions are met:

```tsx
conditionals: [
  {
    variants: { variant: "primary" },
    modifiers: ["loading"],
    className: "bg-blue-400"
  }
]
```
</Accordion>
</AccordionGroup>

## Return Value

The style object provides two main capabilities:

### Component Application

Apply styles to any React component:

<CodeGroup>
```tsx Apply to Component
const Button = buttonStyles(ButtonPrimitive)
const LinkButton = buttonStyles('a')
```

```tsx Usage
<Button variant="primary" size="lg" disabled>
  Styled Button
</Button>
```
</CodeGroup>

### Style Extraction

Extract computed class names for advanced use cases:

<CodeGroup>
```tsx Extract Classes
const classes = buttonStyles.extract({ 
  variant: "primary", 
  size: "lg" 
})
// Returns: "px-4 py-2 rounded ... bg-blue-500 text-white ... px-6 py-3 text-lg"
```

```tsx Use with Libraries
// Framer Motion
<motion.button 
  className={buttonStyles.extract({ variant: "primary" })}
  whileHover={{ scale: 1.05 }}
>
  Animated Button
</motion.button>

// Server-side rendering
const classes = buttonStyles.extract(props)
return `<button class="${classes}">${children}</button>`
```
</CodeGroup>

## Examples

### Simple Button

<Frame>
```tsx
const buttonStyles = recast.styles({
  base: "inline-flex items-center justify-center rounded font-medium transition-colors",
  variants: {
    variant: {
      primary: "bg-blue-500 text-white hover:bg-blue-600",
      secondary: "bg-gray-200 text-gray-900 hover:bg-gray-300"
    },
    size: {
      sm: "h-8 px-3 text-sm",
      md: "h-9 px-4 py-2",
      lg: "h-10 px-6 text-lg"
    }
  },
  modifiers: {
    disabled: "opacity-50 cursor-not-allowed",
    fullWidth: "w-full"
  },
  defaults: {
    variants: { variant: "primary", size: "md" }
  }
})

const Button = buttonStyles(ButtonPrimitive)
```
</Frame>

### Complex Component with Nested Styling

<Frame>
```tsx
const cardStyles = recast.styles({
  base: {
    root: "rounded-lg border bg-white shadow-sm",
    header: "px-6 py-4 border-b",
    title: "text-lg font-semibold",
    content: "px-6 py-4"
  },
  variants: {
    size: {
      sm: {
        header: "px-4 py-2",
        content: "px-4 py-3"
      },
      lg: {
        header: "px-8 py-6", 
        content: "px-8 py-6"
      }
    }
  },
  modifiers: {
    elevated: {
      root: "shadow-lg"
    }
  }
})

// Primitive receives styles via cls prop
function CardPrimitive({ cls, title, children }) {
  return (
    <div className={cls?.root}>
      <div className={cls?.header}>
        <h3 className={cls?.title}>{title}</h3>
      </div>
      <div className={cls?.content}>{children}</div>
    </div>
  )
}

const Card = cardStyles(CardPrimitive)
```
</Frame>

## TypeScript Integration

Recast automatically generates TypeScript types:

<Frame>
```tsx
const buttonStyles = recast.styles({
  variants: {
    variant: { primary: "...", secondary: "..." },
    size: { sm: "...", md: "...", lg: "..." }
  },
  modifiers: {
    disabled: "...",
    loading: "..."
  }
})

const Button = buttonStyles(ButtonPrimitive)

// TypeScript automatically infers:
type ButtonProps = {
  variant?: "primary" | "secondary"
  size?: "sm" | "md" | "lg"
  disabled?: boolean
  loading?: boolean
  className?: string
  // + all ButtonPrimitive props
}
```
</Frame>
