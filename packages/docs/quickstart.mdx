# Build your first component

This guide will walk you through creating a complete button component using Recast. You'll learn the core concepts while building something useful.

<Note>
  **Already installed Recast?** Jump straight to [Step 1](#step-1-create-a-component-primitive). Otherwise, follow our [installation guide](/installation) first.
</Note>

## What you'll build

By the end of this guide, you'll have a fully-typed, reusable button component with multiple variants, sizes, and modifiers:

<CodeGroup>

```tsx Final Output
const Button = buttonStyles(ButtonPrimitive)
```

## Step 1: Create a component primitive

First, create a basic button component that accepts standard HTML button props:

```tsx ButtonPrimitive.tsx
import React, { ButtonHTMLAttributes, forwardRef } from 'react'

interface ButtonPrimitiveProps extends ButtonHTMLAttributes<HTMLButtonElement> {
  children: React.ReactNode
}

export const ButtonPrimitive = forwardRef<HTMLButtonElement, ButtonPrimitiveProps>(
  ({ children, ...props }, ref) => {
    return (
      <button ref={ref} {...props}>
        {children}
      </button>
    )
  }
)

ButtonPrimitive.displayName = 'ButtonPrimitive'
```

<Tip>
  **Why create a primitive?** This separation allows your component logic to be completely independent of styling. You can reuse this primitive across different projects with entirely different visual designs.
</Tip>

## Step 2: Define your styles

Now create a reusable style definition using Recast:

```tsx Button.tsx
import { recast } from '@rpxl/recast'
import { ButtonPrimitive } from './ButtonPrimitive'

const buttonStyles = recast.styles({
  // Base classes applied to all variants
  base: "inline-flex items-center justify-center rounded-md font-medium transition-colors focus-visible:outline-none focus-visible:ring-1 focus-visible:ring-ring disabled:pointer-events-none disabled:opacity-50",
  
  // Mutually exclusive variants
  variants: {
    variant: {
      primary: "bg-blue-500 text-white hover:bg-blue-600",
      secondary: "bg-gray-100 text-gray-900 hover:bg-gray-200",
      outline: "border border-gray-200 bg-transparent hover:bg-gray-50",
      ghost: "hover:bg-gray-100",
    },
    size: {
      sm: "h-8 px-3 text-sm",
      md: "h-9 px-4 py-2",
      lg: "h-10 px-6 text-lg",
    }
  },
  
  // Boolean modifiers that can be combined
  modifiers: {
    loading: "cursor-wait",
    fullWidth: "w-full",
  },
  
  // Set sensible defaults
  defaults: {
    variants: { variant: "primary", size: "md" }
  }
})

// Apply styles to your primitive
export const Button = buttonStyles(ButtonPrimitive)
```

## Step 3: Use your styled component

Your button is now ready to use with full TypeScript support:

<CodeGroup>
```tsx Basic Usage
import { Button } from './Button'

function App() {
  return (
    <div>
      <Button>Default Button</Button>
      <Button variant="secondary" size="lg">Large Secondary</Button>
      <Button variant="outline" size="sm">Small Outline</Button>
    </div>
  )
}
```

```tsx With Modifiers
function LoadingExample() {
  const [isLoading, setIsLoading] = useState(false)
  
  return (
    <Button 
      variant="primary" 
      loading={isLoading}
      fullWidth
      onClick={() => setIsLoading(!isLoading)}
    >
      {isLoading ? 'Loading...' : 'Click me'}
    </Button>
  )
}
```
</CodeGroup>

<Check>
  **TypeScript magic:** Notice how you get full autocomplete for `variant`, `size`, `loading`, and `fullWidth`. Invalid combinations are caught at compile time!
</Check>

## Step 4: Add conditional styling

Let's add more sophisticated styling logic using conditionals:

```tsx Button.tsx
const buttonStyles = recast.styles({
  base: "inline-flex items-center justify-center rounded-md font-medium transition-colors focus-visible:outline-none focus-visible:ring-1 focus-visible:ring-ring disabled:pointer-events-none disabled:opacity-50",
  
  variants: {
    variant: {
      primary: "bg-blue-500 text-white hover:bg-blue-600",
      secondary: "bg-gray-100 text-gray-900 hover:bg-gray-200",
      outline: "border border-gray-200 bg-transparent hover:bg-gray-50",
      destructive: "bg-red-500 text-white hover:bg-red-600",
    },
    size: {
      sm: "h-8 px-3 text-sm",
      md: "h-9 px-4 py-2", 
      lg: "h-10 px-6 text-lg",
    }
  },
  
  modifiers: {
    loading: "cursor-wait",
    fullWidth: "w-full",
    rounded: "rounded-full",
  },
  
  // Apply styles only when specific conditions are met
  conditionals: [
    {
      // Large destructive buttons get extra emphasis
      variants: { variant: "destructive", size: "lg" },
      className: "shadow-lg font-bold"
    },
    {
      // Loading state disables hover effects
      modifiers: ["loading"],
      className: "pointer-events-none opacity-75"
    },
    {
      // Rounded primary buttons get a special gradient
      variants: { variant: "primary" },
      modifiers: ["rounded"],
      className: "bg-gradient-to-r from-blue-500 to-blue-600"
    }
  ],
  
  defaults: {
    variants: { variant: "primary", size: "md" }
  }
})
```

Now your button adapts its styling based on prop combinations:

```tsx
<Button variant="destructive" size="lg">
  {/* Gets shadow-lg font-bold from conditional */}
  Delete Account
</Button>

<Button variant="primary" rounded>
  {/* Gets gradient background from conditional */}
  Gradient Button
</Button>
```

## Step 5: Extract styles for advanced use cases

Sometimes you need the computed class names without rendering a component:

```tsx
// Extract class names for any prop combination
const primaryLarge = buttonStyles.extract({ variant: "primary", size: "lg" })
// Returns: "inline-flex items-center justify-center rounded-md font-medium transition-colors focus-visible:outline-none focus-visible:ring-1 focus-visible:ring-ring disabled:pointer-events-none disabled:opacity-50 bg-blue-500 text-white hover:bg-blue-600 h-10 px-6 text-lg"

// Use with other components or libraries
function CustomComponent() {
  return (
    <motion.button 
      className={primaryLarge}
      whileHover={{ scale: 1.05 }}
    >
      Animated Button
    </motion.button>
  )
}
```

<Tip>
  **Use cases for `.extract()`:**
  - Server-side rendering optimization
  - Integration with animation libraries
  - Dynamic styling in complex applications
  - Testing style computation logic
</Tip>

## Step 6: Add TypeScript types (optional)

For better TypeScript integration in your team, create proper interfaces:

```tsx types.ts
import { ComponentProps } from 'react'
import type { Button } from './Button'

// Extract the component's prop types
export type ButtonProps = ComponentProps<typeof Button>

// Create specific variants for common use cases
export interface PrimaryButtonProps extends Omit<ButtonProps, 'variant'> {
  variant?: 'primary'
}

export interface SecondaryButtonProps extends Omit<ButtonProps, 'variant'> {
  variant?: 'secondary'
}
```
