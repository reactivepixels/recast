## Basic usage

Import and start using Recast in your components:

```tsx
import { recast } from '@rpxl/recast'

const buttonStyles = recast.styles({
  base: "px-4 py-2 rounded font-medium",
  variants: {
    variant: {
      primary: "bg-blue-500 text-white",
      secondary: "bg-gray-200 text-gray-900"
    }
  }
})

const Button = buttonStyles(ButtonPrimitive)
```

## Optional: Global configuration

Configure Recast globally for your application:

```tsx
// app.tsx or your root file
import { recast } from '@rpxl/recast'

recast.configure({
  // Custom class name merging function
  mergeFn: (classes) => classes.join(' '),
  
  // Performance options
  performance: {
    enableLRU: true,
    cacheSize: 500
  }
})
```

## Framework integration

### Tailwind CSS

Recast works perfectly with Tailwind CSS out of the box:

```tsx
const buttonStyles = recast.styles({
  base: "inline-flex items-center justify-center rounded-md text-sm font-medium transition-colors",
  variants: {
    variant: {
      default: "bg-primary text-primary-foreground hover:bg-primary/90",
      outline: "border border-input bg-background hover:bg-accent"
    }
  }
})
```

### CSS Modules

Use Recast with CSS Modules for scoped styling:

```tsx
import styles from './Button.module.css'

const buttonStyles = recast.styles({
  base: styles.button,
  variants: {
    variant: {
      primary: styles.primary,
      secondary: styles.secondary
    }
  }
})
```

### Styled Components

Integrate with styled-components using class name extraction:

```tsx
import styled from 'styled-components'

const StyledButton = styled.button`
  ${props => buttonStyles.extract(props)}
`
```

## TypeScript support

Recast provides excellent TypeScript support out of the box. No additional setup required!

```tsx
import type { ComponentProps } from 'react'

const Button = buttonStyles(ButtonPrimitive)
type ButtonProps = ComponentProps<typeof Button>

// ButtonProps now includes:
// - variant?: "primary" | "secondary"
// - size?: "sm" | "md" | "lg"
// - All ButtonPrimitive props
```

## Troubleshooting

### TypeScript errors

If you're seeing TypeScript errors, make sure you have the latest version of TypeScript installed:

```bash
npm install -D typescript@latest
```

### Class names not applying

Ensure your CSS framework is properly configured and loaded before Recast components render.

### Performance issues

If you notice performance issues with large numbers of components, consider enabling LRU caching:

```tsx
recast.configure({
  performance: {
    enableLRU: true,
    cacheSize: 1000
  }
})
```
