# recast.styles()

Create a reusable style definition that can be applied to any React component or used to extract computed class names.

## Syntax

```tsx
recast.styles(config)
```

## Parameters

### `config` *(object)*

Configuration object that defines the component's styling behavior.

#### `base` *(string | object)*

Base classes applied to all component instances.

- **Type:** `string | Record<string, string>`
- **Required:** No
- **Default:** `""`

**Example:**
```tsx
// String base for simple components
base: "inline-flex items-center justify-center rounded-md font-medium"

// Object base for complex components
base: {
  root: "rounded-lg border bg-white shadow-sm",
  header: "px-6 py-4 border-b",
  content: "px-6 py-4"
}
```

#### `variants` *(object)*

Mutually exclusive styling options. Only one value from each variant group can be active.

- **Type:** `Record<string, Record<string, string | Record<string, string>>>`
- **Required:** No
- **Default:** `{}`

**Example:**
```tsx
variants: {
  variant: {
    default: "bg-black text-white hover:bg-black/90",
    secondary: "bg-slate-100 text-slate-900 hover:bg-slate-100/80",
    destructive: "bg-red-500 text-white hover:bg-red-500/90"
  },
  size: {
    sm: "h-9 px-3 text-sm",
    md: "h-10 px-4 py-2", 
    lg: "h-11 px-8 text-lg"
  }
}
```

#### `modifiers` *(object)*

Boolean flags that can be combined. Multiple modifiers can be active simultaneously.

- **Type:** `Record<string, string | Record<string, string>>`
- **Required:** No
- **Default:** `{}`

**Example:**
```tsx
modifiers: {
  disabled: "opacity-50 cursor-not-allowed",
  loading: "cursor-wait animate-pulse",
  fullWidth: "w-full",
  elevated: "shadow-lg"
}
```

#### `conditionals` *(array)*

Style rules that apply only when specific combinations of variants and modifiers are active.

- **Type:** `ConditionalRule[]`
- **Required:** No
- **Default:** `[]`

**Example:**
```tsx
conditionals: [
  {
    variants: { variant: "default" },
    modifiers: ["loading"],
    className: "bg-black/70" // Lighter background when default + loading
  },
  {
    variants: { size: "sm" },
    modifiers: ["fullWidth"],
    className: "min-h-[2rem]" // Minimum height for small full-width buttons
  }
]
```

#### `defaults` *(object)*

Default values for variants to reduce prop repetition.

- **Type:** `{ variants?: Record<string, string> }`
- **Required:** No
- **Default:** `{}`

**Example:**
```tsx
defaults: {
  variants: { 
    variant: "default", 
    size: "md" 
  }
}
```

## Return value

### `RecastStylesObject`

An object with two main methods:

#### `(component)` - Component Application

Apply the styles to a React component.

**Syntax:**
```tsx
const StyledComponent = styleObject(Component)
```

**Parameters:**
- `Component` - React component or HTML tag string

**Returns:** Styled React component with inferred TypeScript props

**Example:**
```tsx
const Button = buttonStyles(ButtonPrimitive)
const LinkButton = buttonStyles('a')
```

#### `.extract(props)` - Style Extraction

Extract computed class names for advanced use cases.

**Syntax:**
```tsx
const className = styleObject.extract(props)
```

**Parameters:**
- `props` - Object containing variant, modifier, and other style props

**Returns:** `string` - Computed class names

**Example:**
```tsx
const classes = buttonStyles.extract({ 
  variant: "default", 
  size: "lg",
  disabled: true 
})
// Result: "inline-flex items-center justify-center rounded-md text-sm font-medium bg-black text-white h-11 px-8 opacity-50 cursor-not-allowed"
```

## TypeScript support

Recast automatically generates TypeScript types for all variants and modifiers:

```tsx
const buttonStyles = recast.styles({
  variants: {
    variant: { default: "...", secondary: "..." },
    size: { sm: "...", md: "...", lg: "..." }
  },
  modifiers: {
    disabled: "...",
    loading: "..."
  }
})

const Button = buttonStyles(ButtonPrimitive)

// TypeScript automatically infers:
type ButtonProps = {
  variant?: "default" | "secondary"
  size?: "sm" | "md" | "lg"
  disabled?: boolean
  loading?: boolean
  className?: string
  // + all ButtonPrimitive props
}
```

## Examples

### Simple button

```tsx
const buttonStyles = recast.styles({
  base: "inline-flex items-center justify-center rounded-md text-sm font-medium transition-colors",
  variants: {
    variant: {
      default: "bg-black text-white hover:bg-black/90",
      secondary: "bg-slate-100 text-slate-900 hover:bg-slate-100/80"
    }
  },
  defaults: {
    variants: { variant: "default" }
  }
})

const Button = buttonStyles('button')
```

### Complex component with nested elements

```tsx
const cardStyles = recast.styles({
  base: {
    root: "rounded-lg border bg-card text-card-foreground shadow-sm",
    header: "flex flex-col space-y-1.5 p-6",
    title: "text-2xl font-semibold leading-none tracking-tight",
    content: "p-6 pt-0",
    footer: "flex items-center p-6 pt-0"
  },
  variants: {
    size: {
      sm: {
        header: "p-4",
        content: "p-4 pt-0",
        footer: "p-4 pt-0"
      },
      lg: {
        header: "p-8",
        content: "p-8 pt-0", 
        footer: "p-8 pt-0"
      }
    }
  },
  modifiers: {
    elevated: {
      root: "shadow-lg"
    },
    outlined: {
      root: "border-2"
    }
  }
})

function CardPrimitive({ cls, title, children, footer, ...props }) {
  return (
    <div className={cls?.root} {...props}>
      {title && (
        <div className={cls?.header}>
          <h3 className={cls?.title}>{title}</h3>
        </div>
      )}
      <div className={cls?.content}>{children}</div>
      {footer && <div className={cls?.footer}>{footer}</div>}
    </div>
  )
}

const Card = cardStyles(CardPrimitive)
```

### With conditionals

```tsx
const buttonStyles = recast.styles({
  base: "inline-flex items-center justify-center rounded-md text-sm font-medium transition-colors",
  variants: {
    variant: {
      default: "bg-black text-white hover:bg-black/90",
      outline: "border border-input bg-background hover:bg-accent"
    },
    size: {
      sm: "h-9 px-3",
      md: "h-10 px-4 py-2",
      lg: "h-11 px-8"
    }
  },
  modifiers: {
    loading: "cursor-wait",
    disabled: "opacity-50 cursor-not-allowed"
  },
  conditionals: [
    {
      variants: { variant: "default" },
      modifiers: ["loading"],
      className: "bg-black/70"
    },
    {
      variants: { variant: "outline" },
      modifiers: ["loading"],
      className: "border-slate-300"
    }
  ],
  defaults: {
    variants: { variant: "default", size: "md" }
  }
})
```
