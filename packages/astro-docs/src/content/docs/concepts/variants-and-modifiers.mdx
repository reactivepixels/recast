# Variants & Modifiers

Recast provides two complementary ways to style your components: **variants** for mutually exclusive options and **modifiers** for combinable boolean flags.

## Variants

Variants are mutually exclusive styling options. Only one value from each variant group can be active at a time.

```tsx
const buttonStyles = recast.styles({
  base: "px-4 py-2 rounded font-medium",
  variants: {
    variant: {
      default: "bg-black text-white",
      secondary: "bg-slate-100 text-slate-900"
    },
    size: {
      sm: "px-3 py-1 text-sm",
      md: "px-4 py-2",
      lg: "px-6 py-3 text-lg"
    }
  }
})

const Button = buttonStyles(ButtonPrimitive)
```

**Usage:**
```tsx
<Button variant="default" size="lg">
  Default Large Button
</Button>

<Button variant="secondary" size="sm">
  Secondary Small Button  
</Button>
```

:::tip[Think radio buttons]
Variants work like radio buttons - you can only select one option from each group.
:::

### Common variant patterns

**Visual variants:**
```tsx
variant: {
  default: "bg-black text-white",
  secondary: "bg-slate-100 text-slate-900", 
  destructive: "bg-red-500 text-white"
}
```

**Size variants:**
```tsx
size: {
  sm: "h-8 px-3 text-sm",
  md: "h-9 px-4 py-2", 
  lg: "h-10 px-6 text-lg"
}
```

## Modifiers

Modifiers are boolean-based styles that can be combined. Multiple modifiers can be active simultaneously.

```tsx
const buttonStyles = recast.styles({
  base: "px-4 py-2 rounded font-medium",
  modifiers: {
    disabled: "opacity-50 cursor-not-allowed",
    loading: "cursor-wait",
    fullWidth: "w-full",
    elevated: "shadow-lg"
  }
})
```

**Usage:**
```tsx
<Button disabled>
  Disabled Button
</Button>

<Button loading fullWidth elevated>
  Loading Full-Width Elevated Button
</Button>
```

:::tip[Think checkboxes]
Modifiers work like checkboxes - you can combine multiple flags together.
:::

### Common modifier patterns

**State modifiers:**
```tsx
modifiers: {
  disabled: "opacity-50 cursor-not-allowed",
  loading: "cursor-wait animate-pulse",
  active: "ring-2 ring-blue-500"
}
```

**Layout modifiers:**
```tsx
modifiers: {
  fullWidth: "w-full",
  centered: "mx-auto",
  elevated: "shadow-lg"
}
```

## Combining variants & modifiers

The power of Recast comes from combining variants and modifiers:

```tsx
const buttonStyles = recast.styles({
  base: "inline-flex items-center justify-center rounded-md font-medium transition-colors",
  variants: {
    variant: {
      default: "bg-black text-white hover:bg-black/90",
      secondary: "bg-slate-100 text-slate-900 hover:bg-slate-100/80"
    },
    size: {
      sm: "h-8 px-3 text-sm",
      md: "h-9 px-4 py-2",
      lg: "h-10 px-6 text-lg"
    }
  },
  modifiers: {
    disabled: "opacity-50 cursor-not-allowed",
    fullWidth: "w-full",
    loading: "cursor-wait"
  },
  defaults: {
    variants: { variant: "default", size: "md" }
  }
})

const Button = buttonStyles(ButtonPrimitive)
```

**Example combinations:**

<div class="flex flex-col gap-3 p-5 my-4 bg-slate-50 dark:bg-slate-900 rounded-lg border border-slate-200 dark:border-slate-700">
  <button class="recast-button recast-button--default recast-button--md">Default (uses defaults)</button>
  <button class="recast-button recast-button--secondary recast-button--lg" style="width: 100%;">Large Secondary Full-Width</button>
  <button class="recast-button recast-button--default recast-button--sm" disabled>Small Default Disabled</button>
</div>

```tsx
// Uses defaults: variant="default" size="md"
<Button>Default Button</Button>

// Override variants, add modifiers
<Button variant="secondary" size="lg" fullWidth>
  Large Secondary Full-Width Button
</Button>

// Multiple modifiers
<Button size="sm" disabled>
  Small Disabled Button
</Button>
```

## Default values

Set default values to reduce repetition:

```tsx
const buttonStyles = recast.styles({
  variants: {
    variant: { default: "...", secondary: "..." },
    size: { sm: "...", md: "...", lg: "..." }
  },
  defaults: {
    variants: { variant: "default", size: "md" }
  }
})

// These are equivalent:
<Button>Click me</Button>
<Button variant="default" size="md">Click me</Button>
```

## TypeScript integration

Recast automatically generates proper TypeScript types:

```tsx
const Button = buttonStyles(ButtonPrimitive)

// TypeScript infers:
type ButtonProps = {
  variant?: "default" | "secondary"
  size?: "sm" | "md" | "lg" 
  disabled?: boolean
  loading?: boolean
  fullWidth?: boolean
  // + all ButtonPrimitive props
}
```
