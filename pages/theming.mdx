# Theming with Recast

The theme layer is where the visual presentation of the component is defined. It
ensures that our styles are entirely decoupled from the component primitive,
maximizing reuse. This guide will detail the creation of a theme layer for a
component primitive and explain the individual properties available to fulfill
any design requirements.

> While the examples below use [Tailwind CSS](https://tailwindcss.com/), Recast
> works with any CSS solution, including CSS modules, CSS-in-JS libraries, or
> plain CSS classes.

## Creating a Themed Component

To create a themed component, import your component primitive and use the new
`recast.styles()` function:

```jsx
import { recast } from "@rpxl/recast";
import ButtonPrimitive from "@/components/primitives/button";

const buttonStyles = recast.styles({
  // Theme object
});

export const Button = buttonStyles(ButtonPrimitive);
```

The `recast.styles()` function takes a theme object that defines the styling,
and returns a function that can be applied to any component.

Let's explore the structure of the theme object:

## Theme Object Structure

### Base Styles

Base styles are always applied to the component:

```jsx
const buttonStyles = recast.styles({
  base: "inline-flex items-center justify-center rounded-md font-medium transition-colors",
  // ...
});

export const Button = buttonStyles(ButtonPrimitive);
```

### Variants

Variants define different variations of your component:

```jsx
const buttonStyles = recast.styles({
  // ...
  variants: {
    variant: {
      primary: "bg-blue-500 text-white hover:bg-blue-600",
      secondary: "bg-gray-200 text-gray-800 hover:bg-gray-300",
      outline: "border border-gray-300 text-gray-700 hover:bg-gray-100",
    },
    size: {
      sm: "px-3 py-2 text-sm",
      md: "px-4 py-2 text-base",
      lg: "px-6 py-3 text-lg",
    },
  },
  // ...
});

export const Button = buttonStyles(ButtonPrimitive);
```

### Modifiers

Modifiers are boolean properties that can be combined with variants:

```jsx
const buttonStyles = recast.styles({
  // ...
  modifiers: {
    fullWidth: "w-full",
    rounded: "rounded-full",
  },
  // ...
});

export const Button = buttonStyles(ButtonPrimitive);
```

### Conditionals

Conditionals allow you to apply styles based on combinations of variants and
modifiers:

```jsx
const buttonStyles = recast.styles({
  // ...
  conditionals: [
    {
      variants: { variant: "primary", size: "lg" },
      className: "font-bold shadow-lg",
    },
    {
      modifiers: ["fullWidth"],
      className: "justify-center",
    },
  ],
  // ...
});

export const Button = buttonStyles(ButtonPrimitive);
```

### Defaults

You can specify default values for variants and modifiers:

```jsx
const buttonStyles = recast.styles({
  defaults: {
    variants: { variant: "primary", size: "md" },
    modifiers: ["rounded"],
  },
  base: "inline-flex items-center justify-center font-medium transition-colors",
  variants: {
    variant: {
      primary: "bg-blue-500 text-white hover:bg-blue-600",
      secondary: "bg-gray-200 text-gray-800 hover:bg-gray-300",
    },
    size: {
      sm: "px-3 py-2 text-sm",
      md: "px-4 py-2 text-base",
      lg: "px-6 py-3 text-lg",
    },
  },
  modifiers: {
    rounded: "rounded-md",
    fullWidth: "w-full",
  },
});

export const Button = buttonStyles(ButtonPrimitive);
```

## Advanced Features

### Nested Component Styling

For complex components with multiple parts, you can use object syntax:

```jsx
const sliderStyles = recast.styles({
  base: {
    root: "relative flex w-full touch-none select-none items-center",
    track:
      "bg-secondary relative h-1.5 w-full grow overflow-hidden rounded-full",
    range: "bg-primary absolute h-full",
    thumb: "border-primary bg-background block h-4 w-4 rounded-full border-2",
  },
  variants: {
    size: {
      sm: {
        root: "h-4",
        track: "h-1",
        thumb: "h-3 w-3",
      },
      lg: {
        root: "h-6",
        track: "h-2",
        thumb: "h-5 w-5",
      },
    },
  },
});

export const Slider = sliderStyles(SliderPrimitive);
```

### Style Composition

You can compose multiple style objects for modular design:

```jsx
const baseStyles = recast.styles({
  base: "inline-flex items-center justify-center",
});

const colorStyles = recast.styles({
  variants: {
    variant: {
      primary: "bg-blue-500 text-white",
      secondary: "bg-gray-500 text-white",
    },
  },
});

const sizeStyles = recast.styles({
  variants: {
    size: {
      sm: "px-2 py-1 text-sm",
      lg: "px-6 py-3 text-lg",
    },
  },
});

// Compose all styles together
const ComposedButton = recast.compose([baseStyles, colorStyles, sizeStyles])(
  ButtonPrimitive,
);
```

### Class Name Extraction

Extract computed class names without rendering:

```jsx
const buttonStyles = recast.styles({
  base: "rounded px-4 py-2",
  variants: {
    variant: { primary: "bg-blue-500", secondary: "bg-gray-500" },
    size: { sm: "text-sm", lg: "text-lg" },
  },
});

// Extract class names for given props
const className = buttonStyles.extract({ variant: "primary", size: "lg" });
// Returns: "px-4 py-2 rounded bg-blue-500 text-lg"
```

### Global Configuration

Configure Recast behavior globally:

```jsx
import { recast } from "@rpxl/recast";
import { cn } from "./utils/cn";

recast.configure({
  mergeFn: cn, // Custom class merging function
  performance: {
    enableMonitoring: true, // Performance monitoring in development
    cacheSize: 200, // LRU cache size
  },
});
```

This setup provides a powerful, flexible theming system that scales with your
application while maintaining excellent performance and developer experience.
